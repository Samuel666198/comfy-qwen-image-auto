# Qwen Image 2.1 生图/编辑

ComfyUI 单节点封装，节点名为 **Qwen Image 2.1 生图/编辑**（`QwenImage21Auto`）。安装目录：`ComfyUI\custom_nodes\comfy_qwen_image_auto`。

## 使用

1. 填写画面描述。文生图时不添加参考图；编辑时把图片拖入参考图区域，或点击「＋」选图。最多 10 张。
2. 参考图按画面上的编号排列。拖动左上角把手，或点底部左右箭头调整顺序；点击图片可替换，点 × 删除。在画面描述中输入 `@`，选图后会插入带缩略图的行内标签。标签始终指向原图片，换序后编号自动更新；删图后会显示失效，生成时提示重新选择。旧提示词里的 `<image1>` 等手写引用仍可使用。
3. 参数悬浮面板中选画幅、分辨率与推理强度。画面描述里只有一个明确比例（如 `3:4`、`16:9`）时，画幅会自动切换；出现不同的多个比例时保持当前值。手动改选后，继续编辑同一比例的文字不会强制改回。480p、768p、1K、2K、4K 分别以 480²、768²、1024²、2048²、4096² 为方形等效总像素预算，宽高由画幅决定并取 32 的倍数，例如 1K 的 16:9 约为 1376×768。4K 对显存需求很高。参考图编辑仍沿用首张参考图的画幅，自定义宽高则优先决定输出尺寸。
4. 点击提示词下方的参数摘要按钮，打开悬浮参数面板。推理强度显示为低 18 步、中 24 步、高 40 步、自定义 1～200 步。启用有效 LoRA 后切换自定义并保留步数，禁用或移除后不自动切回。旧工作流保留原步数。
5. LoRA 可逐行添加、在悬浮列表搜索并选模型、改强度、暂时停用或删除。按 Esc 或点击列表外可取消，取消不会添加空行。停用保留文件和强度；强度 0 会原样保留。
6. TE-speed 位于「推理加速」，Qwen 2.1 的 Prefix KV 缓存位于独立的「模型缓存」。两者各最多一张卡片，可停用、展开设置、移除及重新添加。停用或移除 KV 卡片会明确关闭模型内置缓存，可能增加每步耗时；重新启用时先配置缓存，再应用 TE-speed。
7. 常用悬浮面板集中设置画幅、总像素预算、推理强度、种子、排除内容和 RTX。负面词默认「不使用」，可选择预设或输入自定义内容。模型、CFG、重绘和采样器位于「高级」悬浮面板。
8. 种子支持固定、随机、递增值、递减值。本次使用输入值，成功入队后准备下一次值；提交失败不更新，已入队后取消不回退。结果上方显示本次实际使用的种子。
9. 参考图可直接拖入提示词区域，缩略图位于输入框上方，可删除、排序和通过 @ 引用。点击「生成」提交当前节点及必要上游；任务期间锁定编辑，可取消本节点发起的任务。预览显示阶段和采样估时，初值按每步约 3 秒计算，随后根据实际速度修正。
10. 结果位于提示词上方，保留最近 10 次成功生成记录和参数快照，可重命名。点击图片右上角「⋯」显示下载、大图查看、RTX 超分。超分设置默认 2 倍 / ULTRA，提供 1.5×、2×、4×和自定义 1～4 倍小数；只处理所选原图，保留原图与超分版本，不改变原节点 image 输出或消耗生图种子。

## 本轮验证与更新方式（2026-09-26）

独立测试服务中完成 18 步、1024×1024 实际生成（约 34.7 秒，包含加载等阶段），RTX 2 倍 ULTRA 输出 2048×2048（约 1.6 秒）。验证了独立排队/运行任务取消、保存重开、重命名、下载和放大；自动测试 35 项 JavaScript、12 项 Python 通过。耗时只是本次机器和配置的实测值。

更新后请重启常用 ComfyUI 服务，并新开页面或强制刷新。取消使用 `/api/jobs/{id}/cancel` 原子接口；旧核心不支持时会明确提示，不回退全局中断。原生操作系统文件拖入尚需手动确认（浏览器合成拖放通过）；4K 和高倍率显存可行性未实测。启用 KV 时仍可能遇到此前记录的核心缓存问题。

## 平铺参数面板（2026-09-26）

常用参数采用约 520px 宽浮层，选项平铺，选中紫色高亮。画幅不再提供自定义入口（旧工作流的自定义尺寸仍保留）。步数、种子与超分倍率点击「自定义」在原按钮位置输入，回车或失焦确认，Esc 撤销；确认后显示「自定义」，悬停显示实际值。种子四种变化模式独立于输入值。

参数摘要、高级、扩展、生成位于同一行；「扩展」按钮切换 LoRA/推理加速/模型缓存组件区，默认折叠且状态随工作流保存，悬停按钮显示启用摘要。RTX 自动转换为 RGB 三通道，超分图不带 Alpha，原图保留。倍率支持 1～4 小数，官方 RTX 输出宽高会对齐到 8 像素。

本轮需重启 ComfyUI 后刷新页面，才能加载 FLOAT 倍率定义；旧服务的 INT 定义会把 1.5 四舍五入。已通过 35 项 Node、13 项 Python 测试，独立服务实测 RGBA 64×64 经 1.5× ULTRA 输出 RGB 96×96。

## 提示词与图片操作

提示词框固定 120px 输入高度，超出内容滚动；右上角放大按钮打开浮层，沿用同一个编辑器和 @图片标签，实时同步。点击「完成」、Esc 或浮层外关闭。生成期间禁止编辑。

图片右上角「⋯」打开下载、大图查看、RTX 超分菜单。已有超分版本时再次点击 RTX 会提示确认；继续会从原图重做，替换当前超分版本引用，取消不提交。原图/超分图旁的「对比」打开左右滑杆对比，拖动竖线或操作顶部滑杆切换可见范围；尚无超分版本时禁用。

本轮仅前端更新，刷新页面即可；此前的默认命名、小数倍率后端改动若尚未重启，仍需重启一次。

## 保存与兼容

新工作流保存参考图的稳定 ID 与排列、提示词内标签的稳定引用、LoRA 的启用状态，以及 TE-speed / KV 配置。旧工作流的参考图和 LoRA 数据仍可读取；没有 `accel_json` 时沿用旧的 TE-speed 与 KV 参数。当前扩展保持原输入和模型注入端口；连接 `model`、`clip`、`vae` 可替代内部模型加载。

参考图文件会上传到 ComfyUI 的 `input` 目录；换机器时需要一并复制相应文件。输出为 `image`、`model`、`latent`、`status`。`status` 会报告跳过或失败的加速组件。修改 Python 后端后需要重启 ComfyUI 服务；只刷新页面不足以更新节点输入定义。

本界面基于 ComfyUI 前端 1.53.6 验证。更换前端版本时应重新检查自绘控件的显示、拖放和序列化。


### 图片管理与永久删除

图片下方“图片管理器”管理当前节点作品，默认按生成顺序，可切换名称/时间排序。支持多选及 ZIP 下载。菜单删除与批量删除会永久删除原图及已记录的超分文件，确认后无法撤销，失败项保留记录。参考图不参与删除。扩展按钮现在打开悬浮窗。此次更新新增后端接口，需要重启服务并刷新页面。


### 图片版本与提示词历史

普通生成创建作品；重新生成图标、图片编辑、RTX超分追加版本。菜单“版本历史”切换、查看参数或载入提示词与参数；回滚后新增编号继续递增。对比使用前一个仍存在的版本；下载及批量ZIP仅导出当前选中版本。删除其他版本需要确认，会永久删除文件，编号不复用。

输入 @ 可引用当前节点已生成的任意版本，并加入参考图缩略图。引用固定版本，不随作品切换。编辑入口保存原草稿并引用当前图片；退出编辑恢复原草稿。提示词历史图标位于放大按钮左侧，保留最近50条，可载入、复制、删除；删除文本不会删除图片。

本轮需要重启ComfyUI服务并刷新页面。旧图片记录自动迁移；此前未记录的旧超分文件无法追溯为版本。

### 提示词优化与清空

提示词右上角依次是优化、清空、历史、放大。清空前保存快照，保留参考图；复制与清空会显示短暂反馈。优化成功后替换当前文字，原文可从历史恢复；失败不覆盖原文，也不会自动开始生图或改变画幅。

在「扩展 → 提示词优化」可切换 Ollama / Responses API。Ollama 默认服务地址为 `http://127.0.0.1:11434`，模型列表显示本机已安装模型；更多参数可设温度和输出上限，优化结束后尝试卸载本次模型。

Responses API 默认地址为 `https://api.deepseek.com`，默认模型 `deepseek-flash`。API 模型按钮会刷新服务提供的模型列表；远程服务不支持由插件下载模型，若服务未提供 `/models`，可手动填写模型 ID。推理强度根据服务返回的信息显示；设为“模型默认”时不发送该参数。

API 地址和密钥保存在 ComfyUI 的本机 user 配置 `user/qwen_image_auto_prompt_optimizer.json`。密钥不会写入工作流；工作流仅保存服务模式、模型名称及推理强度等非密钥偏好。API 密钥只由本机后端读取并通过 Bearer 鉴权发送，不进入前端优化请求体或错误日志。

有参考图时，最终改写请求会把图片与提示词一起发送给所选视觉模型，顺序对应 `@图片` 标签。模型列表明确声明不支持图片时会阻止编辑优化；服务未声明能力时会尝试发送，若服务拒绝图片则显示错误，不会静默退化为纯文本优化。前置模板分类仅接收提示词和图片数量，不发送图片。

活动中的路由、文生图、编辑和功能模块模板均为中文；改写结果跟随用户输入语言。规则参考千问官方提示词增强方案：使用连贯自然语言、完整保留用户的明确约束，编辑时说明修改与保留内容，准确对应多图角色。官方 PE 模板是面向专用微调模型的上游原文副本，保存在 `prompts/` 供追溯，不由通用 Ollama / Responses 优化链路直接加载；详情见 `prompts/SOURCES.md`。优化期间暂时禁止节点编辑和生成。API 取消会终止当前请求；Ollama 取消时还会尝试卸载本地模型。

### 蒙版局部重绘

提示词右上角保留蒙版重绘与图片编辑。蒙版编辑器提供紫色涂抹（实际重绘范围）、彩色画笔（红/绿/蓝/黄视觉标注）、空心矩形框（框内作为重绘范围）和橡皮擦，并支持撤销/重做、清空、笔刷大小与羽化。每条彩色标注可单独输入和修改对应要求。

确认后按标注区域自动生成方位文字，例如“在图片右上角蓝色标注区域”。图片中心分界用于区分四角；标注跨越中线时使用“上方/下方/左侧/右侧”，覆盖中心时使用“中央”。编辑说明封装在“局部修改”标签内，自动替换当前提示词；先前提示词会保存在历史快照中，不会参与本次重绘。

模型收到原图与叠加紫色涂抹/彩色标注的辅助图；独立黑白蒙版用于最终合成。输出恢复原图尺寸，蒙版外像素及透明度保持原样。来源必须保持第一张参考图，彩色标注图在内部追加到最后，用户参考图最多9张。区域状态随工作流及提示词/生成快照保存；辅助图与蒙版上传到input目录，迁移工作流时一并保留。

参考图、@候选缩略图与已插入标签支持悬停预览；@列表显示缩略图，长名称省略，版本号保留。底部扩展按钮位于高级与复制之间。本轮新增后端输入，需要重启服务并刷新前端。

### 工作台细节更新（2026-09-29）

提示词框右下角显示字符数与 1024 tokens 折算容量（例如 `x/y`），按当前中英文字符比例估算，标点与 @图片可见标签计入；该值仅作提示，不截断文本。工具栏的透明通道图标可切换并常亮，提交时会在运行提示词前加入透明背景约束；实际透明效果仍由模型遵循提示词决定。

提示词优化按钮先打开补充要求窗口。确定后补充要求、提示词和参考图片一起发送给当前 Ollama / Responses 模型；取消不发请求。思考阶段显示状态和计时，不显示思考内容；开始最终输出后以流式方式显示改写文本。

图片导航、对比、版本和图片管理器改为紧凑图标按钮，版本入口显示 `V1` 等编号。双击预览图也可打开原有放大查看器；查看器通过指针捕获拖动，关闭浏览器原生图片拖拽。图片管理器选择或排序后保留滚动位置；ZIP 文件名使用 `qwen_image_YYYY_MM_DD_NN.zip`，当天序号递增。生成遮罩向图片内容边缘外扩约 2px。

本次修改包含 Python 优化接口和前端模块。更新后请重启 ComfyUI 服务并重新加载桌面端页面。桌面端具体呈现、透明背景模型遵循效果以及 ZIP 下载行为尚需在当前 ComfyUI 实例手动确认。
