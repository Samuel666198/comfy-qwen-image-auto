# Qwen 图片管理器智能归档设计

日期：2026-09-29。状态：用户已确认；实现、自动化验证与集成复审均已完成。

## 目标与范围

在现有图片管理器中增加按日期整理、归档引用限制、版本管理和文件容量信息。沿用当前工作台作品历史、版本状态、结果管理器、图片查看器及安全文件接口；不改变 ComfyUI 核心、节点连接、生成流程或已有图片路径。本设计只整理当前节点工作台已记录的图片与文件夹，不把 `output/qwen_auto` 扩展成另一套全局图库。

## 已确认的交互

1. **智能整理入口**：图片管理器标题栏增加“智能整理”，点击后在浮层选择“图片整理”或“文件夹整理”。整理结果以管理器内的虚拟文件夹显示，不在磁盘上移动或重命名文件。
2. **图片整理**：将管理器已记录的作品按日期分入 `yyyy_mm_dd` 虚拟文件夹。日期优先从图片文件名读取，其次取作品和版本创建时间中最早的有效时间，仍不可用时使用文件修改时间。归入整理结果的作品标记为已归档。
3. **文件夹整理**：将管理器已知的现有物理子文件夹按月份归入 `yyyy_mm` 虚拟分组，不移动物理目录。每个作品以最早生成版本的物理目录作为代表目录（缺失时取最早版本），避免一个作品因超分等版本位于不同目录而重复进入多个归档组。月份优先从代表目录名识别有效月份，其次取该作品的图片日期；仍无法识别的项目留在未归档区，不猜测月份。归入整理结果的图片标记为已归档。
4. **归档与引用**：已归档作品仍可在管理器查看、下载和恢复版本浏览，但不出现在 `@` 新增引用候选中。已在提示词/参考图中存在的引用不自动删除或改写，以免破坏已保存工作流；用户移除引用后，归档作品不能再次新增引用。
5. **版本信息与浏览**：每张作品继续显示当前版本号，如“当前 V2”；存在其他版本时，在下一行以灰色小字显示“另有 3 个版本”（数字不含当前选中版本）。图片右键菜单新增“查看其他版本”，调用现有版本选择/查看窗口，不另建一套查看器。
6. **清除其他版本**：归档文件夹顶部和图片右键菜单提供“一键清除其他版本”。操作目标是该文件夹内当前选中的作品：保留其当前选中版本，删除该作品的其他版本；文件夹中的其他作品不受影响。二次确认显示作品名、保留版本、待删版本数量，并说明会永久删除磁盘文件。取消时不改变文件或状态。
7. **容量信息**：管理器标题栏显示当前管理范围的总磁盘占用；单图显示文件大小，虚拟文件夹显示其所含图片及版本文件的总大小。前端打开管理器时批量请求后端文件元数据；后端复用安全路径解析并对文件执行 `stat`。按规范化文件路径去重后统计，避免同一文件被多个版本描述重复计算。读取失败的文件不计入数值并显示可辨认的缺失/未知状态。
8. **关闭入口**：图片管理器关闭按钮固定在标题栏最右侧。

## 状态与数据边界

- 继续以当前节点的 `qwenWorkbench.history` 作品/版本数组为作品清单和唯一版本真源，不新建平行作品数据库。
- 在现有作品状态中追加归档标记及虚拟分组信息；旧工作流缺少字段时默认为未归档，迁移不得移动、重命名或删除文件。
- “图片整理”分组作品记录；“文件夹整理”展示这些作品已有 `file.subfolder` 中的目录关系，并在管理器内按月份聚合。虚拟分组只影响管理器组织与新引用候选，不改变 ComfyUI 文件描述符。
- 在 `result_files.py` 增加批量文件大小元数据路由，复用现有安全路径解析；删除版本时复用现有删除路由并遵循共享文件保护：如果待删文件仍被保留版本/作品引用，则不删除物理文件，并在结果中报告跳过；仅从目标作品移除该历史版本记录。
- 容量统计只覆盖当前节点工作台管理器可以识别的作品版本文件，不扫描或计入其他节点、工作流和 `qwen_auto` 目录中的无关文件。

## 错误处理与兼容

- 作品文件缺失或读取大小失败时，其他作品仍可正常显示和整理。
- 删除接口逐文件返回成功/失败；部分失败的版本记录保留供用户重试。共享文件不能因清理而损坏。
- 被永久删除版本仍可能被旧工作流、提示词快照或已保存参考图路径引用；这些外部引用无法完整枚举。二次确认须说明删除后相应路径将失效，前端已有引用需显示缺失状态，不得自动替换成其他图片。
- 已归档作品仍可从管理器解除归档并回到未归档区；解除归档不移动文件，也不自动加入提示词引用。此操作用于纠正误归档，避免虚拟归档无法恢复。

## 验收标准

- 整理前后所有源文件路径和磁盘位置不变；旧工作流可继续读取原路径。
- 日期/月份识别、回退日期和未知日期分组符合上述规则；重复整理幂等，不产生重复作品或重复版本。
- 归档作品不出现在新的 `@` 候选中；未归档作品仍可引用；已有引用标签保持原身份和文件路径。
- 单图正确显示当前 Vn 与其他版本数量；右键“查看其他版本”复用现有版本窗口并显示同作品全部仍存在版本。
- 清理时只作用于目标作品：取消确认零删除；确认后保留选中版本、删除同作品其他可删除版本；同文件夹其他作品完整；共享文件保留；部分失败状态可重试；版本编号不复用。
- 单图、虚拟文件夹及管理器总占用均按唯一文件路径汇总；文件大小读取失败不阻断界面。
- 对旧工作流迁移、归档状态序列化与恢复、桌面端和浏览器端交互做针对性验证；永久删除仅在隔离临时图片上测试。

## 风险与限制

- 当前作品列表来自单个工作流节点的历史状态；管理器统计和整理范围因此限于该节点已记录的作品，不能代表整个 ComfyUI 输出目录的空间占用。
- 删除其他版本是永久性磁盘删除；代码回退不能恢复已删除文件。外部工作流引用不可枚举，因此必须进行清晰的二次确认。
- 删除其他版本是永久性磁盘删除；代码回退不能恢复已删除文件。外部工作流引用不可枚举，因此必须进行清晰的二次确认。实施期间未执行生产图片删除。
- 项目位于 `feat/qwen-image-archive-manager` 分支。初始化时没有基线提交，当前项目文件尚未暂存或提交；准备首个提交前应检查 `.gitignore` 与 `git status`。

## 实施结果

- 新增安全文件元数据路由；管理器按唯一规范路径显示总量、单图和归档文件夹容量。
- 新增仅保存于工作流历史的虚拟日期/月归档；归档作品不进入新的 `@` 候选，现存引用保持原状。
- 管理器卡片显示其他版本数量，右键可调用既有图片查看与版本历史；文件夹清理要求只选中一个作品，保留当前选中版本。
- 删除接口将因其他工作引用而保留的文件单独返回 `skipped`，前端提示共享文件仍保留在磁盘。
