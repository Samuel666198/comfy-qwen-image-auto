# Qwen Image 2.1 面板下一轮更新设计

## 目标

在现有 ComfyUI 单节点内完成拖图去重、参考图排序、LoRA/加速组件的临时禁用，以及面向创作的紧凑布局和推理强度预设。保持旧工作流可打开、旧参数可执行。

## 范围与边界

- 本轮实现参考图稳定身份与拖动排序，界面显示 1–10 的顺序号。替换图片保留该位置的身份；删除只移除选中的图片。后端继续按数组顺序传入 `image_1`…`image_10`。
- 本轮不实现提示词 `@` 联想或富文本标签。稳定身份为下一轮 `@` 引用准备；旧的 `<image1>` 写法继续有效。下一轮设计 `@` 时应让引用绑定图片身份，排序只更新显示序号，删除后明确标记失效。
- 加速组件先限定为现有的 TE-speed 与 Qwen KV 缓存，每种最多一张卡片，按现有后端顺序执行。添加、禁用、重新启用、移除均是界面状态；不开放任意第三方节点或同种多次叠加。
- 不新增节点内“运行”按钮，仍使用 ComfyUI 的工作流运行入口；不替换底层模型加载、采样或图像解码链路。

## 交互布局

默认视图从上到下为：提示词 → 带序号的参考图 → 画幅/尺寸 → 推理强度 → LoRA 列表 → 加速组件 → 高级设置。LoRA 与加速卡片各有启用开关、设置入口和删除按钮；禁用保留全部配置并变灰。高级设置收纳模型文件、种子、CFG、降噪、负面词、采样器和缓存细节，折叠时显示非默认值摘要。

没有参考图时显示文生图画幅与尺寸；有参考图时默认显示“跟随参考图”，避免显示一个后端会忽略的比例值。自定义宽高仍可在高级设置中明确选择。模型/clip/vae 输入端口已连接时，摘要显示“使用外部输入”，不暗示内部文件选择仍会生效。

推理强度提供“快速 / 均衡 / 精细 / 自定义”，基础模型的首版映射仅改 `steps`：12 / 18 / 40；其他底层参数保留用户现值。18 维持本节点现有默认值，40 参考 [Qwen 官方示例](https://huggingface.co/Qwen/Qwen-Image-2.1)。手动修改步数后显示“自定义”；修改 CFG 等独立高级参数只更新折叠摘要，不改变推理强度档位。文案用“偏向速度/细节”，不保证每张图都随步数提升质量。识别到已启用的 Viggle Turbo LoRA 时，不把基础模型三档套用到它；显示[专用采样要求](https://huggingface.co/Viggle/Qwen-Image-2.1-viggle-turbo/blob/main/README.md)并转为自定义。此轮不改造成 Turbo 专用 sigma 采样链路。

## 数据与兼容

- `refs_json` 每项新增稳定 `id`，继续保存 `name`；读取旧字符串或旧 `{name}` 项时补 ID。后端忽略 ID，顺序仍由数组决定。
- `lora_json` 每项新增 `enabled`，缺失视为 `true`；禁用时后端跳过该项，删除时才从数组移除。强度 0 必须保持为 0，不能回退成 1.0。
- 新增可选 `accel_json`：空字符串表示旧工作流，沿用 `enable_te_speed`、`cache_device` 等现有字段；非空时采用卡片列表 `[{type, enabled, config}]`。允许的 type 仅为 `te_speed` 与 `kv_cache`，未知项忽略并写入 status。卡片缺席与 `enabled:false` 都不执行，但界面分别表现为已移除与暂时禁用。
- 新增可选 `inference_preset` 仅保存 UI 选择；实际采样仍使用 `steps` 等已有参数。旧工作流没有该值时，18 步可显示“均衡”，其他值显示“自定义”；不得重写旧参数。
- 保存、关闭并重新打开工作流后，图片顺序、禁用状态、组件卡片状态、预设和折叠摘要一致。

## 错误和验收

- 仅参考图面板内的图片文件 drop 被扩展同步接管，并阻止 ComfyUI 的文档级默认图片节点创建；面板外拖入保持原行为。接管必须发生在异步上传前。
- 上传失败时显示可见错误，不增加缩略图或 `refs_json` 项。满 10 张时不接受第 11 张，已有图片仍可替换。
- TE-speed 不可用时不能只显示“已启用”；保留设置并显示未安装或运行失败状态。禁用后不调用其后端逻辑。
- 使用真实 ComfyUI 页面验证布局、交互、JSON 序列化、工作流重开；用针对性测试验证旧数据迁移、0 强度、禁用和拖图事件拦截。实际出图与耗时对比单独记录，未跑则不宣称预设画质效果。
