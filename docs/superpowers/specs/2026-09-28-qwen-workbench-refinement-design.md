# Qwen 创作面板细节优化设计

日期：2026-09-28。状态：已确认并按本方案实施。

## 目标与范围

在现有 Qwen Image 2.1 创作面板内完成提示词区、结果工具栏、图片管理和查看器的小幅完善。沿用现有 DOM 组件、节点状态、流式优化 API 和结果查看器，不改 ComfyUI 核心、不替换前端架构、不改变工作流节点连接。

本轮范围包含：提示词长度估算、透明背景提示开关、优化补充指令弹窗及等待状态、批量管理列表滚动修复、ZIP 命名、预览遮罩覆盖，以及结果工具栏图标化、图片双击放大和查看器拖动修复。

## 已确认交互

1. **提示词长度**：输入框右下角显示 `x/y`。`x` 是当前可见提示词的 Unicode 字符数（标点计入，图片引用按标签可见文本计数）；`y` 是以 1024 tokens 为目标、根据中文字符/标点与英文文本比例折算的近似字符容量。该值仅作软提示，不限制或截断输入；说明中标明估算性质。Qwen-Image 2.1 的 ComfyUI 编码节点没有公开字符数上限，故不将该估算称为模型硬上限。
2. **透明背景**：提示词工具栏新增可切换图标按钮。开启时紫色高亮并给出“透明通道已开启”反馈；状态保存到当前节点属性。提交生成时在实际送入工作流的提示词前附加透明背景要求，不修改编辑器原文。此功能仅增加提示词约束，不承诺将 RGB 输出后处理成真正 Alpha 通道。
3. **提示词优化**：点击优化后先打开悬浮对话框，提供可选补充要求、确定与取消。确定后把补充要求、当前提示词和参考图片一并提交给当前 Ollama 或 Responses API 优化模型；取消不发请求。补充要求不覆盖原提示词，优化成功后仍只用模型返回的提示词回填。
4. **优化等待态**：显示简洁动画、已用时间和处理阶段。思考内容永不显示；处于思考/路由阶段只显示状态，开始收到最终输出后显示流式提示词。未开启思考时收到输出即切换为流式文本。停止或错误时保留原提示词并反馈状态。
5. **图片管理和导出**：勾选、排序或重命名后保留管理网格滚动位置及选择状态。ZIP 默认名为 `qwen_image_YYYY_MM_DD_01.zip`，在本机同一天连续打包时序号递增。
6. **预览遮罩**：生成中遮罩略微超出图片预览内容边界，以避免边缘未覆盖；限制在预览容器内，不遮挡节点外部交互。
7. **结果工具栏**：上一张、下一张、对比、版本和图片管理器使用紧凑图标控件并保留 tooltip/无障碍标签；批量管理入口改名为“图片管理器”。版本入口以当前版本号 `V1`、`V2`、`V3` 等显示并继续打开现有版本历史。图片双击调用现有放大查看器。
8. **查看器拖动**：继续使用指针拖动平移；关闭原生图片拖放和文字选择，确保按住图片拖动只改变查看位置，不触发浏览器/桌面端的移动复制拖影。

## 实施选择

推荐沿用 `prompt-editor.mjs`、`QwenImage21Auto.js`、`prompt_optimizer.py`、`result-manager.mjs` 和 `result-preview.mjs` 的现有边界局部扩展，并为用户输入、提示词改写、滚动保留与查看器交互添加有针对性的测试。另一方案是拆出全新工具栏和管理弹窗组件；隔离更强，但扩大改动面且本轮没有共享状态或生命周期需求，因此不采用。

字符折算按可见文本做轻量估算：CJK 字符及标点近似按 1 字符/token，英文连续文本按约 4 字符/token；依据当前文本构成将 1024 tokens 换算为字符容量。它不替代实际模型 tokenizer，也不作为拒绝生成条件。

## 错误处理、兼容与验证

- 补充指令为空时与当前优化行为一致；弹窗取消不保存快照、不开始网络请求。请求失败或取消时不得覆盖原提示词。
- 透明开关保存于节点工作台状态，旧工作流缺失该字段时默认为关闭；提交只在运行时添加约束，不重写保存的提示词字段。
- ZIP 序号只在成功启动下载后推进，日期使用本机日期；存储异常时回退 `_01`，不得阻止下载。
- 滚动修复验证选择多图后选中状态和滚动位置均保留；拖动查看器验证不产生 `dragstart`，仍支持缩放和平移。
- 使用已有 Node 与 Python 测试命令运行受影响测试；另做模块语法检查。桌面端视觉与真实生成效果需在 ComfyUI 重载扩展后人工验证。

## 假设与限制

- `1024 tokens` 是用户指定的估算目标，不是 Qwen-Image 2.1 的正式字符上限。
- 透明背景模式按用户指定采用前置提示词约束，不新增 Alpha 合成节点。
- 项目目录没有 `.git`，无法按 brainstorming 技能要求提交本设计文档；本文保存在已有设计文档目录，实施前由用户审阅。
