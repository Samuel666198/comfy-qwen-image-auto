# Ollama 提示词工具（用户已批准）

## 范围

- 提示词右上角：优化、清空、历史、放大。清空前保存最近50条快照，保留参考图；清空及复制显示短暂反馈。
- 扩展浮窗配置本机 Ollama 地址、实际已安装模型、实际支持的思考选项，折叠温度和输出上限。配置随工作流保存，不下载模型。
- 使用短路由提示词按需选择少量本地模块，再组合精简的生图/编辑基础提示词；有参考图时必须视觉模型，按原顺序送图，稳定引用与 `<imageN>` 转换。上游 Qwen 提示词保留为来源参考，模板来源与组装方式记录在 prompts/SOURCES.md。
- 成功只回填提示词，不自动生成或覆盖画幅；原文入历史。优化期间节点交互锁定，过期请求不回填已恢复/移除的节点。
- 分类和改写共用同一个 Ollama 会话，改写响应流式传给前端；成功、失败或断连均在流程结束时显式卸载本次模型。仅允许本机地址，不修改其他已加载模型。

## 实现边界

前端扩展现有 prompt-editor、extensions-popover，新增纯引用转换与 Ollama 设置模块。后端独立 HTTP 路由，不修改采样及生图任务协议。主服务由用户重启加载新路由。

## 本轮实现补充

- 路由器只输出固定模块 ID，白名单校验失败时退回任务基础模板；多参考图时程序强制加入多图组合模块。
- 改写阶段通过 SSE 展示临时流式预览；完整结果校验成功后才替换提示词。取消会中止客户端读取，后端在检测到连接断开后清理并卸载模型。
- 当前轮只做语法检查，未运行测试或真实 Ollama 推理；桌面端验证需要重启 ComfyUI 后检查。
