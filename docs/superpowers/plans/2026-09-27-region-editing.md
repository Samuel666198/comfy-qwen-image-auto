# 区域编辑初版（已被 2026-09-27 局部编辑修订替代）

此计划记录已完成的初版。后续用户决定移除评论入口，并改用颜色标注、方位提示词和独立重绘蒙版；最新行为以 HANDOFF 顶部的“局部编辑改版”记录及 README 为准。

## 修订后的行为

- 只创建蒙版编辑入口。编辑器的紫色涂抹绘制蒙版；彩色画笔（红/绿/蓝/黄）绘制模型视觉标注；彩色矩形框保持空心显示，框内并入重绘蒙版。
- 紫色蒙版要求和每个彩色标注要求都可在编辑器内修改。提示词按图像中心分界生成四角/四边/中央方位文字，不写坐标；使用局部修改标签封装。确认前保存当前普通提示词快照，提交时提示词只包含本次区域要求。
- 模型视觉辅助图为带标注原图，独立黑白蒙版仅用于结果合成。继续使用原有来源版本和结果追加流程，保存 maskImage 与标注矢量数据。

## 范围

- 提示词工具栏：蒙版重绘、评论、图片编辑、优化、清空、历史、放大。底栏扩展移到高级和复制之间。
- 参考图和 @ 候选/标签悬停大图；候选左侧缩略图、名称省略、版本号保留。
- 评论原图像素坐标点选/框选，多条编号，编辑/删除。确认自动引用来源版本并填入可读区域说明；重复确认替换旧段，手工修改提示确认。
- 蒙版画笔/橡皮擦/矩形，大小、撤销/重做、清空、羽化；确认后使用现有生成流程，结果新增版本。
- 官方明确支持视觉标记/独立蒙版，没有确认纯坐标精确重绘接口。因此评论提交原图加编号辅助图；蒙版提交原图加白改黑留辅助图，结果按蒙版合成，蒙版影响范围之外像素保留。

## 契约

region_json 为附加 forceInput STRING，不插入旧参数顺序。含 mode/source/auxiliary/width/height/feather/comments/drawings/instruction/来源版本及提示词段。
用户参考图不改编号，来源须第一张，辅助图内部追加最后，合计最多10张。辅助图上传到 input，原图和辅助图不写入工作流base64。区域状态保存在editSession及提示词/生成快照。
坐标基于实际原图，不包含显示黑边；结果合成恢复原图尺寸。RGBA蒙版外保留原图RGBA，内部用生成RGBA（RGB生成视为不透明）。羽化双方采用半径feather/2。
优化保留区域说明原文，只优化其余补充文字；来源被删除或辅助图缺失时拒绝提交。退出编辑/切换草稿清理旧区域状态，版本号继续递增。

## 验证

坐标边界与反向框选、参考图上限/来源绑定、快照复制、异步提交冻结、RGB/RGBA蒙版外一致性、真实浮窗和上传、低步数GPU生成及磁盘像素比较。桌面与网页分别报告，不用浏览器验证代替桌面验证。
